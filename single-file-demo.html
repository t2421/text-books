PROLOGUE

章タイトル

章のリード (導入の一文)

本文の最初の段落の冒頭一字は、自動でドロップキャップになる。本文中では 強調、イタリック、code がそれぞれ違う扱いを受ける。

セクション見出し (h3)

章内のセクションは h3 で。朱色のダイヤモンドマーカーが自動で付く。リスト・表・コードもそのまま使える。

  • 箇条書きはこんな見え方になる
  • 左の点は朱色になる
  • 本文と同じ字面で読みやすく
章の核心

章で最も伝えたいメッセージを 墨地の黒札に置く。Dual Coding ── 本文で説明したことを別形式でも提示する設計。

本文の流れを切らずに補足を入れるなら、サイドノートを使う:

補 ── サイドノートのタイトル 本文の脇に置く補足情報。読み飛ばしても本筋は失われない、けれども興味があれば読み込める情報を入れる。

注意してほしいポイントを、短く伝える。--warn は朱、--info は鉄紺、--note は黄土に変えられる。

CHAPTER ONE

二段構えと引用

章を「思想 / 実務」の二段構えで書くときのマークアップ

長文教科書では、各章を 「I. 思想」 と 「II. 実務」 の二段構えで書くと、読者が「概念」と「行動」を切り分けて受け取れる。h3 にバリアントを当てれば、視覚的にもラベルがつく:

I. 思想主張をここに置く

「思想」パートは .h3--thought + .h3__tag で書く。ダイヤモンドマーカーが鉄紺になり、左上にラベルが立つ。著者がここで伝えたい 輪郭を述べる場所。

引用元の人物名と日付 "This is how an English original quote looks ── italic display font for Latin chars, with the source URL underneath." — 出典タイトル (リンクは点線)

原文を残したい引用は .sidenote.sidenote--quote を使う。辰砂色の縦線に切り替わり、.sidenote__original がイタリック表記、.sidenote__attr が出典のクレジット。

II. 実務月曜の朝から何を変えるか

「実務」パートは .h3--practice。マーカーが黄土色になり、ラベルも切り替わる。抽象論を行動に落とす段落をここに置く。

項目意味例
h3通常のセクション見出しマーカー: 朱
h3.h3--thought思想パートの見出しマーカー: 鉄紺 / ラベル: 鉄紺
h3.h3--practice実務パートの見出しマーカー: 黄土 / ラベル: 黄土
章末や核心の引用は blockquote で。
余白を広く取り、読者の頭を一度休ませる。

  • 実務.h3--practice + .h3__tag で黄土のセクション

CHAPTER TWO

図解を含む章

概念を視覚化するときのマークアップ

SVG をインラインで .figure に入れる。デザイントークン (墨・辰砂・黄土) と同じ色をハードコードすれば、本文の色調と合う。

図のあとは、その図が示すポイントを言葉でも繰り返すと理解が安定する。視覚と言語の両方で同じ概念に触れる Dual Coding の応用。

CHAPTER SUMMARY

この章で押さえたこと

  • .figure ── SVG を本文の幅外まで広げる枠
  • SVG のフォントは Noto Serif JP に揃えると統一感が出る
  • 色は #1c1917 (墨) / #a01c1c (辰砂) / #8b6914 (黄土) を直書きでOK

EPILOGUE

締めの章

読者を送り出す最後の章

エピローグでは、ここまでの内容を改めて俯瞰し、読者を送り出す。引用ブロックで印象を残すと余韻になる:

テンプレートは古びる。
でも、組版の規律は古びない。

これで textbook-ds の主要コンポーネントは全部出てきた。新しい教科書はここから組み立てていく。
